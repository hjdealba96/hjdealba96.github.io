# Henry De Alba's professional profile

Personal portfolio website at [hjdealba96.github.io](https://hjdealba96.github.io).

Built on the [Start Bootstrap Resume](https://startbootstrap.com/theme/resume) template (v7.0.5, MIT licensed) with a custom dark/light color system, redesigned UI components, and updated content.

## Quick start

Open `index.html` in a browser or run:

```
python3 -m http.server
```

No build step required. Push to `master` to deploy via GitHub Pages.
